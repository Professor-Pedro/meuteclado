# Meu Teclado IA

Teclado Android (pt / en / es) com barra de IA: Corrigir, Reescrever, Responder, Traduzir (PT/EN/ES) e Desfazer.
Usa a API do Google Gemini com a sua própria chave (plano gratuito). A chave fica só no aparelho.

## Como compilar só com o celular
1. Suba esta pasta para um repositório no GitHub (branch `main`).
2. Aba **Actions** > workflow **Build APK** roda sozinho (ou "Run workflow").
3. Em **Releases** baixe `MeuTecladoIA.apk` e instale (permita "fontes desconhecidas").
4. Abra o app, ative o teclado, escolha-o, cole a chave do Google AI Studio e salve.

## Como usar
- Selecione um texto (ou deixe o campo inteiro) e toque em Corrigir / Reescrever / → PT / → EN / → ES.
- Responder: copie a mensagem recebida, abra o campo de resposta e toque em Responder.
  O que você digitou antes vira instrução (ex.: "diga que sim, mas só amanhã").
- ↩ desfaz a última ação de IA. Toque longo em a e i o u c n mostra os acentos.
